# お母さんの参考書

静的HTMLで構成した、年齢・状況別の暮らしのガイドです。トップページの検索・絞り込み、60本の詳細ガイド、オリジナルSVGイラストを含みます。

公開URL: https://u-hyt.github.io/hyu-site/mama/

- `index.html` — ガイドの入り口、年齢・状況検索、進学対策ガイドへの案内
- `guides/` — 60本の暮らしガイド
- `assets/` — オリジナルのSVGイラスト、ファビコン
- `style.css`, `app.js` — レスポンシブ表示と絞り込み
- `sitemap.xml` — 新サイトの公開ページ

ガイド内のAmazon検索リンクは、AmazonアソシエイトのトラッキングID `hyusiteguide-22` を使用しています。個別商品のレビュー・使用実績・順位づけは記載していません。健康・安全に関する内容は一般情報であり、個別の専門相談に代わりません。
