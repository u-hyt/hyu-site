小学校入学準備の道具チェックリスト｜学校指定を確認して選ぶ

ランドセル・上履き・学用品・雨具などを、学校への確認事項、選び方、買う時期、使い始めの練習まで細かく整理したチェックリストです。

暮らしの小ワザ

学校プリントを『買う／家にある／確認待ち』の3列に分ける。上履きは試着時にかかと・つま先・甲を確認し、名前を書く場所も決めておきます。

まずはここをチェック

  • 学校の指定（形・色・袋・名前の位置）を確認
  • 足のサイズを測り、可能なら靴下を履いて試す
  • 上履き袋の寸法と、出し入れのしやすさを確認
  • 記名して、始業前に一度出し入れを練習

忙しい日に続けるには、問題が起きる場面を一つに絞り、道具・手順・置き場をその場で完結できる形にするのがポイントです。

  3. 3. 家族で一度試す

    置き場や使い方を子どもと練習し、困った点を学校へ確認する。 小学校入学準備の道具チェックリスト｜学校指定を確認して選ぶは、使う場所や家族の生活時間によって続けやすい形が変わります。最初から完璧を目指さず、まず一か所だけ変えて効果を見ます。

数日試してから、残す工夫とやめる工夫を決めます。道具を買い足す前に、今ある物の置き場所を変えるだけで解決することもあります。

最初に確認：買い物より先にする3つのこと

  1. 学校・自治体から届いた案内を一か所に集める。入学説明会資料、就学通知、用品注文書、健康・アレルギー関係の連絡をまとめます。案内の更新日と問い合わせ先も控えます。
  2. 持ち物を4つに分ける。「学校指定で必須」「必要だが仕様は自由」「学校に確認中」「入学後に判断」に分類します。購入時期が近い物だけを先に買うと、指定違いや重複を減らせます。
  3. 子どもと家の物を一緒に確認する。家にある文房具や袋が使える場合もあります。新しく買う前に、状態・サイズ・学校のルールを確かめます。
印刷して使える買い物メモ

品名｜学校指定・サイズ｜家にある／譲り受ける｜購入先・期限｜記名方法｜確認先、の6欄を作ります。未確認の欄は「確認待ち」にして、説明会後に埋めます。

入学準備の道具チェックリスト

下の項目は確認のための一覧です。全ての学校で必要とは限りません。説明会資料や学校からの連絡を優先し、「購入する」と決まった物だけ選んでください。

通学かばん・ランドセル

  • 確認：指定の色・形、置き場所、補助バッグの可否、置き傘や防犯用品の扱い。
  • 選ぶ：子どもが背負って歩ける重さ・背負いやすさ、開閉のしやすさ、A4教材や連絡袋の出し入れ、反射材、雨の日の手入れ、保証と修理受付。
  • 試す：薄い服と上着の両方で背負い、肩ベルトを調整。空の状態で一人で背負う・下ろす・留め具を扱えるか確かめます。
  • 買い急がない：流行の付属品を先に追加せず、必要な容量や仕様を確認してから本体・カバーを選びます。

通学靴・上履き・袋

  • 確認：通学靴・上履きの形や色、体育館履きが必要か、袋の大きさ・持ち手・記名位置。
  • サイズ：夕方など足が少し広がる時間に両足を試着。つま先、かかと、甲の当たりを本人に聞き、歩く・しゃがむ動作も確認します。
  • 使いやすさ：マジックテープやひも等は学校のルールに合うものを。本人が座って脱ぎ履きし、左右を見分けられるか試します。
  • 手入れ：洗い替えや持ち帰り頻度を確認し、袋は靴を入れた状態で出し入れできる寸法か確かめます。

筆箱・鉛筆・消しゴム・定規

  • 確認：筆箱の形、鉛筆の濃さ・本数、キャップ、定規、色鉛筆などの指定。キャラクターや音の出る物を避ける指定がある学校もあります。
  • 選ぶ：机の上で開け閉めしやすく、中身が見つけやすいこと。鉛筆は本人が削りやすく、消しゴムは小さな手でも持ちやすい大きさ。
  • 練習：家で鉛筆を削る、筆箱に戻す、消しゴムで消す動作を一緒に試します。名前は学校指定の位置を確認してから付けます。

ノート・連絡帳・ファイル

  • 確認：学年・教科ごとのサイズ、マス目、行数、冊数、連絡帳やプリントファイルの仕様。最初は学校配布や一括購入の場合もあります。
  • 選ぶ：案内に「後日購入」とある物は先に買わない。持ち帰りプリントの量やランドセルに入る寸法も確認します。
  • 管理：提出物用と保管用を分ける場合、子どもが色や置き場所で見分けられる仕組みにします。

体操着・帽子・体育用品

  • 確認：体操着の色・形・販売店、名札、体育帽の指定、体育館履き、水泳用品の購入時期や授業開始時期。
  • サイズ：試着して腕・膝を動かせるか確認。成長を見越しすぎて大きくしすぎると動きづらいことがあります。販売店の交換条件も確認します。
  • 袋：体育着・靴が入る寸法と、濡れ物を持ち帰る場合の袋の指定を確認。洗濯表示と乾きやすさも比べます。

雨具・傘・反射用品

  • 確認：傘を使うルール、置き傘、レインコートの可否、傘立てや名前を書く位置。
  • 選ぶ：子どもの身長に合い、開閉や留め具を自分で扱える傘。視界を遮りすぎず、先端や骨に破損がないか点検します。
  • 歩く練習：傘をさして周囲が見えるか、たたんで袋にしまえるかを安全な場所で試します。反射材は学校・通学路の案内に沿って追加します。

給食・水筒・ハンカチ類

  • 確認：給食の方式、給食袋・ランチョンマット・箸等の要否、食物アレルギーの連絡手順、水筒や飲料の校内ルール。
  • 選ぶ：必要と分かった品のみ、洗いやすく乾かしやすい物を選びます。水筒は満水での重さ、開閉、本人が飲めるかを確認します。
  • 試す：袋のひもを結ぶ、箸箱を開ける、水筒を閉めるなど、実際に使う動作を家庭で試します。

名前付け・予備品

  • 確認：ひらがな・漢字、名字だけかフルネームか、記名位置、名前を付けてよい素材、書類での表記ルール。
  • 選ぶ：布・プラスチック・金属など素材に合う方法を確認。洗濯や水洗い後に剥がれないか、目立たない箇所で試します。
  • 予備：鉛筆や靴下などの買い置きは、入学後の使い方や学校の指定が分かってから。替えを一度に多く買わず、サイズ・消耗を見て補充します。

買う時期と、後回しにしてよい物

  1. 入学案内が届いたら：説明会日、指定品、注文締切、納品日、学校への質問先をカレンダーに書きます。
  2. 学校の説明を聞いた後：指定品・寸法・記名方法を確定し、学校注文品と個人購入品を分けます。
  3. 使用開始が近づいたら：毎日使うかばん・靴・筆記具を用意し、サイズと動作を本人と一緒に確認します。
  4. 入学後に確認：予備品、追加収納、学習机などは、家の置き場所と実際の宿題・持ち帰り量を見て決めます。
買い直しを避ける小ワザ

注文書や学校案内の該当行をスマートフォンで撮り、買い物リストと一緒に保存。店頭や通販で寸法・品番を照合できます。迷った物は購入前に学校へ問い合わせ、回答日と内容もメモしておきます。

入学前に一度だけやってみる「朝の練習」

新しい生活を完璧に再現する必要はありません。休日に、玄関へ出るまでの道具の流れを短く試し、難しかった箇所だけ直します。

  1. 時間割や学校の案内を見て、翌日の物を子どもと一緒にかばんへ入れる。
  2. 靴・上着・雨具を自分で用意し、かばんを背負って玄関まで歩く。
  3. 連絡袋や水筒など、出し入れに時間がかかった物を記録する。
  4. 道具の置き場所と準備の担当を家族で相談し、見える場所に簡単な順番表を貼る。

通学路の確認は、自治体や学校の案内を見て保護者と実際に歩きます。危険な横断場所や困った時に助けを求める場所を確認してください。

予算が気になるときの確認先

必要品をすべて新品でそろえるとは限りません。学校指定の購入方法、学校や地域の譲渡・リユース、就学援助などの制度について、学校または市区町村の教育委員会に相談できます。対象条件・申請期限・対象費目は自治体ごとに異なるため、最新の公式案内を確認してください。
